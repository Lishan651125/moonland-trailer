# 《好好陪自己》分鏡分析

## 製作原則

- 原始分鏡圖是視覺母片；不修改、不覆寫、不移動、不重新生成。
- 本短片以細微環境動態、2.5D 視差與克制的鏡頭運動為主，避免大幅改變臉部、肢體或手指姿勢。
- 建議採 16:9、24fps。一般鏡頭 4–6 秒，補鏡 2–3 秒；完整版本約 90–110 秒。
- 日間使用焦糖金色與溫暖奶油色；進入夜晚後轉為深藍城市光與暖橙室內光。

## 故事節奏

疲憊地開始一天 → 在擁擠與工作中撐住自己 → 被時間與待辦推著走 → 回家後又收到工作訊息 → 主動暫停 → 用一杯熱飲、窗景與安靜把注意力帶回自己。

## 轉場語言與聲音方向

- 日間：用日光、玻璃反射、車窗、文件遮擋做匹配剪接；環境聲可用鳥鳴、捷運低頻、鍵盤與辦公室空調。
- 夜間：用窗框、時鐘、燈光亮度與蠟燭火焰做柔和溶接；環境聲轉成都市遠車聲、冰箱／店內低噪、房間安靜與熱飲蒸氣。
- 片尾讓環境聲漸弱，保留極淡音樂尾音與城市遠景，讓文字有完整停留時間。
